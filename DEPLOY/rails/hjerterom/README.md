# hjerterom

## Community support platform

hjerterom is a locality-aware mutual aid and community support system built on Rails 8.

It focuses on loneliness reduction, volunteer coordination, care infrastructure, neighborhood trust, and local resilience.

## Value proposition

Modern communities have lost many local support systems.

hjerterom helps neighborhoods rebuild:

- trust
- support
- recurring social contact
- volunteer systems
- care coordination
- local resilience
