# baibl

## Scripture and theology platform

baibl is a collaborative scripture, theology, annotation, and study platform built on Rails 8.

It combines semantic scripture search, theological discussion, historical context, collaborative annotation, and AI-assisted study into one shared theology graph.

## Value proposition

Most Bible apps are readers.

baibl is a study and knowledge system.

It should help users:

- explore themes
- compare interpretations
- connect doctrines
- build study groups
- preserve annotations
- understand historical context

## Core concepts

### Theology graph

Connect:

- verses
- doctrines
- theologians
- denominations
- historical events
- places
- languages
- commentaries

### Semantic reading

Users should navigate by:

- grief
- forgiveness
- justice
- loneliness
- leadership
- mercy
- resurrection

instead of only chapter and verse.

### Collaborative annotation

Allow churches, schools, seminaries, and study groups to build shared notes and discussion systems.

### Historical layers

Overlay:

- maps
- empires
- migrations
- rulers
- timelines
- archaeology

### AI study systems

Support:

- semantic retrieval
- translation comparison
- historical explanation
- theological summaries
- guided study
- sermon preparation
