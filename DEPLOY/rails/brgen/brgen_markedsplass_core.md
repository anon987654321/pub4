# Markedsplass Core

Public domain: markedsplass.brgen.no

Markedsplass is the Bergen local marketplace surface inside Brgen Core.

Core dependencies:

- Brgen identity
- Brgen feed
- Brgen media pipeline
- Brgen notifications
- Brgen moderation
- Brgen search
- Brgen messaging

The subapp should not duplicate users, profiles, comments, media uploads, notifications, or moderation infrastructure.
