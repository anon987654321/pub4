# Brgen Feed

The Brgen feed is the realtime Bergen activity graph.

The feed aggregates activity from all Brgen verticals.

## Feed sources

- posts
- comments
- listings
- playlists
- videos
- recipes
- restaurant activity
- local events
- recommendations

## Feed rules

- locality-aware ranking
- moderation-aware visibility
- vertical filtering
- recommendation weighting
- freshness scoring
- social relevance

## Vertical filters

Users should be able to filter the root feed by:

- markedsplass
- spilleliste
- tv
- takeaway
- recipes
- discussion

while still staying inside one Bergen activity graph.
