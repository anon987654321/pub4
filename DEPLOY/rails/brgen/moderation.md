# Brgen Moderation

Moderation should be shared across all Brgen verticals.

## Shared moderation systems

- reports
- visibility states
- review queues
- spam detection
- media review
- locality-aware moderation
- trust scoring
- audit logs

## Shared moderation targets

- posts
- comments
- listings
- videos
- playlists
- recipes
- profiles
- messages

## Design rules

- one moderation kernel
- one report system
- one moderation audit trail
- shared moderation events
- shared moderation tooling

Subapps should contribute policies and review surfaces, not duplicate moderation infrastructure.
