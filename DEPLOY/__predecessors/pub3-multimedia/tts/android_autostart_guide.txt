🔧 TO START ON ANDROID BOOT (Optional):
You need to install Termux:Boot app from F-Droid:
1. Open F-Droid

2. Search for "Termux:Boot"

3. Install the app

4. Open Termux:Boot once to enable it

5. Grant "autostart" permission in Android settings

Once Termux:Boot is installed:
- Comfy Voice will start automatically when your phone boots

- It runs in the background

- Uses wake-lock to prevent sleep
