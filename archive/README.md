# Archive

This directory contains historical implementations preserved for reference.

## MASTER_v1/

Legacy MASTER v2.0 implementation (Unix pipeline toolkit) archived on 2026-02-11.

This was the original MASTER system before the Constitutional AI (v1.0) redesign in MASTER2.
The active system has been moved to the repository root.

**Note:** This code is preserved for historical reference but is not actively maintained.

## legacy_root_lib/

Original root-level `lib/` files that were replaced by MASTER2's library modules during restructuring.
These files are kept for reference in case any functionality needs to be recovered.
