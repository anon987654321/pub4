# Archive Folders

This repository contains several archived/reference folders that are not part of the core MASTER2 system:

## .mp3/ (14MB)
Music samples - appears to be audio files for demos or testing purposes.

## __lora/ (7.8MB)  
LoRA model training data for ME2 (Mass Effect 2?) character. Contains training guide and images.
Not related to MASTER2 core functionality.

## bp/ (9MB)
Business presentations and HTML mockups:
- Bergen healthcare system
- Footwear company presentations  
- Government/NATO presentations
- Various business planning documents

These appear to be client work examples or demos, not core MASTER2 code.

## deploy/ (13MB)
Rails application deployment scripts and examples:
- Multiple Rails app generators (amber, baibl, blognet, brgen, etc.)
- OpenBSD deployment scripts
- Demo/example code for various web applications

These are reference implementations and deployment examples, not part of MASTER2's core refactoring engine.

## :memory:/
Runtime memory folder containing axioms.jsonl - dynamically generated during execution.

---

**Note:** None of these folders are required for MASTER2 core functionality. They can be archived or moved to a separate repository if needed.
