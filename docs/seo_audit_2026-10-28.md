## Session-reported brgen.no observations

The source session reported title Bergen, a Norwegian meta description, absolute
canonical https://brgen.no/, Open Graph site name/title/description/url/type,
a Twitter summary card, and Organization + WebSite JSON-LD with areaServed=Bergen.
It also reported report-only CSP, HSTS with a one-year max-age and preload flags,
a robots file excluding private conversations/messages/admin/profile paths, and a
sitemap containing 2,006 URLs (apex, posts, and user profiles).

These claims need timestamped raw response headers and bodies before being treated
as verified. A response status alone does not establish successful indexability.
