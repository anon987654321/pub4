# CLAUDE.md

MASTER is Claude's #1 primary configuration for this repository. This file
is the one hand-written bootstrap pointer; it holds no policy of its own.

Before planning or acting, read the root `AGENTS.md`. Gemini, GLM, Cursor and
Copilot entry files point there; it carries the shared contract generated from
`MASTER/AGENTS.md`. Tree contracts for RAILS, RAILS/master and OPENBSD live in
`TREE_CONTRACTS.md`.

`MASTER/data/soul.yml` attests the identity body. `MASTER/data/laws.yml` is
the sole normative constitution, and the executable law tree `MASTER/law/`
enforces the catalogue in Ruby.
