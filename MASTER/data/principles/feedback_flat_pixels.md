Keep UI and particle rendering flat two-dimensional—uniform size and alpha, no depth illusion—except when pixels collectively resemble a three-dimensional model such as face mode or future 3D approximations. Idle state uses one pixel at uniform alpha with solid clear.

No z-scaled size, alpha tiers, fake parallax, motion blur, shadows, or gradients. Gyro tilt parallax is acceptable. CSS uses flat fills, hard edges, and pixel borders only.
