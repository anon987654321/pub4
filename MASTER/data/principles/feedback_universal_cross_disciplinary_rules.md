MASTER rules are medium-agnostic principles with per-medium adapters—design, structure, and prose share the same rule. Each rule carries a universal principle and a medium list; detect_structural dispatches parser to tree-walker while logic stays agnostic.

SMALL_PARTS, VERTICAL_RHYTHM, NESTING_DEPTH, and NAMING_SILHOUETTE span code and design. When adding rules, ask what other media apply and reuse existing principles instead of duplicating.
