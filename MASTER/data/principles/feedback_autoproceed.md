Once the user approves a direction or task list, execute the full backlog without per-step want-me-to-X-next prompts. Stop only for destructive shared-state actions, material ambiguity, or an empty backlog.

In multi-commit batches, finish commit pass N and start N+1 without waiting for next. User interruptions override and take priority over the backlog.
