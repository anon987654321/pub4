Do not ask should I continue when autoproceed, decisive signals, or prior approval make yes obvious. After one approval, run the full backlog. State trade-offs such as shipping item one next—not permission questions.

Ask only for destructive actions, ambiguous scope, or real either-or forks where the user's choice materially changes the outcome.
