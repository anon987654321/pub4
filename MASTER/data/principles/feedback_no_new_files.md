Always edit the original file directly. Never create intermediate files—staging copies, _fixed.rb, or tmp patches—without explicit approval. Use Edit on the actual path, or a transient /tmp/patch.rb on the VPS for in-place runs.

Do not persist local copies as a substitute for editing the source file in place.
