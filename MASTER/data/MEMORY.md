# MEMORY

MEMORY holds durable curated facts—plaintext and editable between turns. It captures stable preferences and project context, not raw transcripts.

Project context starts with the [MASTER project context](claude/project_master.md): dev@brgen.no, OpenRouter, Ruby on OpenBSD. [master.yml + master.json authoritative](claude/project_master_yml_json_authority.md) states that Ruby must match constitutional predecessors. The [user is an architect](claude/user_architect_aesthetics.md), so aesthetic proposals are usually approved. [Two Gemfiles](claude/project_master_dual_gemfile.md) means CLI and web Gemfiles are independent. [Falcon + EM subprocess](claude/project_falcon_em_subprocess.md) forbids `Process.fork` inside a Falcon fiber. The [defrag plan 2026-05](claude/project_defrag_plan_2026_05.md) shrinks `data/` and renames paths; Orient was reverted. The [7-module refactor](claude/project_master_seven_module_refactor.md) collapsed `lib/master/` into now, loop, judge, voice, ground, reach, and trace.

Standing principles include [always autofix](principles/feedback_autofix.md), [frequent git commits](principles/feedback_git_commits.md), [no new files without approval](principles/feedback_no_new_files.md), [ultra-minimalistic style](principles/feedback_style.md), [no Python](principles/feedback_no_python.md), and [lint/beautify on touch](principles/feedback_lint_beautify.md). Writing discipline follows [Strunk & White](principles/feedback_strunk_white.md) and [voice — terse, unix](principles/feedback_voice_terse_unix.md). Documentation should [auto-update README](principles/feedback_readme_autoupdate.md). Work stays off-device per [no heavy work on device](principles/feedback_device_limits.md). Markup targets [bare HTML/CSS targeting](principles/feedback_html_css_style.md) and [zsh discipline in shell](principles/feedback_master_zsh_discipline.md).

Operator behavior favors [autoproceed](principles/feedback_autoproceed.md), [no permission questions](principles/feedback_no_permission_questions.md), and [decisive directives](principles/feedback_decisive_signals.md). Formatting bans [consecutive whitespace](principles/feedback_no_consecutive_whitespace.md) and requires [proper casing](principles/feedback_proper_casing.md). After web edits, [restart MASTER after web edit](principles/feedback_restart_rails.md). Layout follows [importance-ordered layout](principles/feedback_importance_order.md). Comments get [reassessed on touch](principles/feedback_comments_reassess.md). Architecture discussions use [meta-architecture framing](principles/feedback_meta_framing.md). Branches sync via [diverged branch sync](principles/feedback_diverged_branch_sync.md). "Run through MASTER" means [scan+fix+council](principles/feedback_run_through_master_triad.md). Shell work avoids [shell piping](principles/feedback_no_shell_piping.md).

Reference material includes [OpenCrabs](claude/reference_opencrabs.md)—the Rust cousin with FTS5 and `/rebuild`—and [Grok UI/CLI patterns](claude/reference_grok_ui_cli_patterns.md) for htmx+SSE, tty-prompt, and char-stream ideas.
