The axioms skill summarizes constitutional rules and invariant checks for the current context. It answers when the operator asks about axioms or when MASTER needs a compact statement of what must hold.

Use the smallest rule set that proves the point, not a lecture. Prefer rules that are verifiable from the repository or session state rather than restating generic principles.
