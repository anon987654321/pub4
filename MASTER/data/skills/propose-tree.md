description: Suggest adjacent improvements from the current change set.
triggers:
  - "propose-tree"

The propose-tree skill suggests adjacent improvements grounded in the current change set. It activates on propose-tree or when the operator wants follow-up work that naturally extends what was just edited or reviewed.

Only propose follow-ups that are directly grounded in current evidence. Each suggestion should tie to a file, finding, or gap already visible in the session so the tree stays actionable rather than speculative.
