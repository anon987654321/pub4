---
name: model
description: Switch or inspect the active model for the current session.
triggers:
  - "\\bmodel\\b"
---

The model skill switches or inspects the active model for the current session. It responds when the operator asks about the model in use or when a task clearly benefits from a different cost–capability tradeoff.

Use the cheapest model that still meets the task, and switch only when the tradeoff is clear. State what changed and why so later turns do not assume a heavier model than necessary.
