# MASTER - Unix Pipeline Architecture

MASTER is a universal code refactoring and completion engine designed as a composable Unix pipeline toolkit.

## Architecture

**Three radical design principles:**

1. **Every module is a standalone executable** that reads JSON from stdin and writes to stdout
2. **SQLite replaces all YAML configs** as the single state layer  
3. **Zsh REPL replaces Ruby CLI** — lightweight orchestration of pipeline stages

## Quick Start

```zsh
# Initialize database
cd MASTER
ruby bin/seed

# Start interactive REPL
bin/start

# Or use shell functions
source .zshrc
m-ask "What is the purpose of this codebase?"
m-quality lib/
```

## Pipeline Stages

All executables in `bin/` are composable via Unix pipes:

### Core Pipeline
- **intake** — Input filter (Strunk & White compression, anti-simulation)
- **guard** — Safety firewall (protection levels, constitutional principles)
- **route** — LLM tier selector (cost-aware, circuit breakers)
- **ask** — Send to LLM, track costs
- **render** — Terminal output (Bringhurst typography)

### Advanced Stages
- **chamber** — Multi-model deliberation (adversarial personas, consensus)
- **critique** — Post-LLM review (cherry-pick synthesis)
- **execute** — Run code blocks safely (sandboxed)
- **evolve** — Self-modification (saga rollback pattern)
- **quality** — Quality gates (Metz rules, complexity, DRY)
- **converge** — Convergence detector (δ < 2% threshold)
- **remember** — Memory store/retrieve (SQLite + embeddings)
- **plan** — 8-phase workflow engine

### Frontend
- **start** — Zsh REPL orchestrator
- **seed** — Import YAML → SQLite

## Pipeline Composition

```zsh
# Simple query
echo '{"text":"fix bug in server.rb"}' | intake | guard | route | ask | critique | render

# With deliberation
echo '{"text":"redesign auth"}' | intake | guard | route | chamber | critique | render

# Autonomous loop
echo '{"text":"optimize lib/"}' | intake | guard | route | ask | critique | execute | evolve

# Quality check
echo '{"files":"lib/*.rb"}' | quality | render

# Memory recall
echo '{"action":"recall","context":"yesterday"}' | remember | render

# Full pipeline with convergence
echo '{"text":"refactor server.rb"}' | intake | guard | plan | route | ask | critique | execute | quality | converge
```

## Database Layer

SQLite replaces all YAML configs and Weaviate:

- **principles** — Constitutional principles with protection levels
- **personas** — Adversarial personas for chamber
- **memory** — Session context and embeddings
- **costs** — LLM usage tracking, daily budgets
- **evolution** — Self-modification history
- **config** — System configuration
- **circuit_breakers** — Model failure tracking
- **quality_checks** — Quality history

Initialize with:
```zsh
ruby bin/seed
```

Inspect with:
```zsh
sqlite3 master.db "SELECT * FROM principles LIMIT 5"
sqlite3 master.db "SELECT SUM(cost_usd) FROM costs WHERE date(created_at,'unixepoch','localtime') = date('now','localtime')"
```

## Design Principles

- **KISS** — 8 library files, 15 executables, each < 200 lines
- **DRY** — Shared code only in lib/
- **Unix Philosophy** — Small, composable, testable tools
- **SOLID** — Single responsibility per module
- **PoLA** — Principle of Least Astonishment

## Dependencies

Minimal:
- `sqlite3` — State layer
- `tty-table`, `tty-box`, `tty-spinner`, `tty-screen` — UI (bin/render only)
- `minitest` — Testing

No heavy frameworks. Uses stdlib `net/http` for LLM calls.

## Migration from v1

The monolithic Ruby application (94 KB `cli.rb`, 132 files) has been replaced with:

- **8 library files** (31 KB total)
- **15 composable executables**
- **Zsh REPL** orchestrator
- **SQLite** single source of truth

Old files backed up to: `/archive_lib_20260206/`
