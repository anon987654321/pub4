## DescriptionxUnit testing framework for Ruby, based on xUnit principles. Designed by Kent Beck for Smalltalk's SUnit.

Ships as a bundled gem in Ruby. To check version, see https://stdgems.org/test-unit/. Install only for newer versions.

test-unit is the original Ruby unit testing library; the other is minitest.

## Features

* test-unit 1.2.3 is the original test-unit from Ruby distribution, distributed as a gem for standalone use.
* Actively improved; may break compatibility with 1.2.3.
* Features available via separate gems, e.g., test-unit-full for GUI runners (Tk, GTK+, Fox).
