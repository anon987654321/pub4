# AI Reasoning Agent

An AI agent that reasons with Ollama and outputs structured markdown.

## Features
- Performs complex reasoning using Ollama.
- Provides an interactive web interface.
- Returns results in markdown for easy sharing.

## Setup
```bashgit clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd ai_agent_tutorials/ai_reasoning_agent
pip install -r requirements.txt
python local_ai_reasoning_agent.py
```

## Usage
1. Open the playground URL.  
2. Enter a query.  
3. View markdown results.

## Details
- The agent handles analytical tasks and produces structured markdown output.  
- The interface supports real‑time interaction and configurable settings.
