# AI Finance AgentTeam with Web Access

A multi‑agent system that performs financial analysis using web search and YFinance data. Agents include a Web researcher, a Finance analyst, and a Team coordinator. Interactions are stored in SQLite.

## Setup

```bashgit clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd advanced_ai_agents/multi_agent_apps/agent_teams/ai_finance_agent_team
pip install -r requirements.txt
export OPENAI_API_KEY='your-api-key'
python3 finance_agent_team.py```

The console outputs a URL; open it to interact via the playground interface.
