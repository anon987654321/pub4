# TripCraft AI  
Travel planning made simple through coordinated AI agents.

## Goal  
Generate a complete travel itinerary from a natural‑language description.

## How It Works  
1. User enters destination, dates, budget, and preferences.  
2. Six specialized agents process the request in parallel.  
3. Agents return data to an Itinerary Specialist that assembles a day‑by‑day plan with bookings and costs.

### Features  
- Personalized plans tailored to travel style.  
- Discovery of niche attractions via advanced search.  
- Optimization of cost, time, and experience.  
- End‑to‑end package output.

## Tech Stack  
- Frontend: Next.js, React, TypeScript  
- Backend: Python, FastAPI, PostgreSQL  
- AI: Agno (coordination), Gemini (LLM), Exa (search), Firecrawl (scraping)  - APIs: Google Flights, Kayak

## Agents  
- **Destination Explorer** – researches attractions.  
- **Hotel Search Agent** – locates lodging.  
- **Dining Agent** – recommends restaurants.  
- **Budget Agent** – optimizes costs.  
- **Flight Search Agent** – plans air travel.  
- **Itinerary Specialist** – composes schedule.
