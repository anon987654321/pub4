# 🎯 Tutorial 8: Simple Multi-Agent Researcher (Runs with ADK)

## 🎯 What You'll Learn- Multi‑agent orchestration using a coordinator with specialized sub‑agents

## 🧠 Core Concept: Multi-Agent Research Pipeline
A coordinator `LlmAgent` runs three specialized agents sequentially: Research → Summarize → Critique. Each agent contributes to a comprehensive research report.
