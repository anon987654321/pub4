# Google ADKCrash Course

## Overview
Google ADK (Agent Development Kit) is a framework for building and deploying AI agents. It works with Gemini and other models and can be deployed anywhere.

## Key Features- Flexible orchestration with workflow and dynamic routing
- Multi‑agent architecture
- Rich tool ecosystem
- Deployment‑ready containers
- Built‑in evaluation
- Safety and security patterns## Learning Path
Tutorials cover:

1. **Starter Agent** – basic agent creation and text processing  
2. **Model‑Agnostic Agent** – OpenAI and Anthropic integrations  
3. **Structured‑Output Agent** – Pydantic schemas for tickets and email  
4. **Tool‑Using Agent** – built‑in, function, third‑party, and MCP tools  
5. **Memory Agent** – in‑memory and persistent conversation storage  
6. **Callbacks** – lifecycle, LLM interaction, and tool execution monitoring  
7. **Plugins** – global callbacks, request/response modification, error handling  
8. **Simple Multi‑Agent** – researcher, coordinator, and critique workflow with web search  
9. **Multi‑Agent Patterns** – sequential, loop, and parallel execution  ## Prerequisites
- Python 3.11+  
- Google AI API key from AI Studio  
- Familiarity with Python and APIs  

## Usage
Each tutorial includes:
- README with concepts  
- Python implementation and Streamlit app  
- `requirements.txt`  

Process:
1. Read the README.  
2. Examine the code.  
3. Run the example.  
4. Experiment.  
5. Move to the next tutorial.
