# Agents

Read `START_HERE.md` and `AGENT_CONTRACT.md` before editing. Bootstrap for coding agents also lives in Ruby runtime: `/orient bootstrap`, `/orient agents`, and `/orient conventions`. Constitutional law is `data/soul.yml` and `data/rules.yml`. VPS deploy is `DEPLOY/OPERATOR.md`.

Default checks:

- ordinary code: `bin/check`
- law, scanner, loop, or agent behavior: `bin/check-agent`
- web face or boot assets: `bin/check-web`
- operator/release pass: `bin/check-full`
