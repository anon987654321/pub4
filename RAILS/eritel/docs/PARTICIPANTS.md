# EriTel participants

The application models intermediaries without assuming that EriTel currently accredits any of them.

## Roles

registrar
Customer-facing registration intermediary.

reseller
Customer acquisition and support channel operating under an EriTel-approved arrangement.

dns_provider
Technical DNS service with only the permissions required for that role.

technical_partner
Other contracted infrastructure or automation provider.

## Status

pending
sandbox
active
suspended
terminated

Only an active participant is eligible for production operations.

## Accreditation flow

1. application;
2. identity and organization verification;
3. contract;
4. sandbox credentials;
5. competency/conformance tests;
6. production approval;
7. active participant status.

The exact requirements belong to EriTel.

## Principle

Participant status is authorization data. A feature toggle is not a substitute for an agreement or accreditation record.
