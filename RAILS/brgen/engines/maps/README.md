# brgen maps

Places and live map for brgen, served at `maps.<city>`
(`maps.brgen.no`, `maps.lsangeles.com`). A mountable Rails engine — see
[`../../ENGINES.md`](../../ENGINES.md). Topology: [`../../AGENTS.md`](../../AGENTS.md).

Not a separate Rails app. Same process, same users, city from the apex.
