# brgen maps

**Places and a live map, for whichever city you arrived through.** maps is a
mountable Rails engine served at `maps.<city>` — `maps.brgen.no`,
`maps.lsangeles.com`. `../../ENGINES.md` is the recipe; `../../AGENTS.md` is the
topology.

It is not a separate Rails app. Same process, same users, and the city comes from
the apex.
