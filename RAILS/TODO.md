## Fixed in the audit tool itself before trusting its output

Sampling the raw findings before trusting them at scale (same discipline as
`MASTER/TODO.md`) turned up three real bugs in `MASTER/lib/design/mobile_first_pwa_profiles.rb`
and `MASTER/lib/rails/rails8_app_audit.rb`, all now fixed and pushed:

1. **CSS extract lambdas read the wrong capture index** (`m[1]` instead of
   `m[0]` on a single-capture `String#scan` match) — every font-size/
   line-height/touch-target finding this tool had ever produced reported
   the value as `0`, always tripping the "below threshold" check
   regardless of the real declared value.
2. **The CSS scan wasn't excluding generated output** — `app/assets/builds/`
   (esbuild/Propshaft build output) and `public/assets/` (Propshaft's
   fingerprinted, gitignored copies) were being scanned alongside real
   source, so a single real violation in a `.scss` partial was reported
   2–4× over (once per compiled/fingerprinted copy). brgen alone dropped
   from 189 to 47 design violations after excluding both.
3. **`focus_ring` checked ERB view templates for a CSS selector pattern**
   (`:focus-visible`) that essentially never appears there — it lives in
   stylesheets. This produced a 100%-false-positive "no focus-visible
   styles found" on every single app, even ones with real focus-ring CSS
   in multiple `.scss` files. Moved the check to scan the CSS corpus
   instead.
4. **`Rails8AppAudit#detect_rails_version`** matched the first line
   containing `gem "rails"` including comments — amber's Gemfile has a
   commented-out alternate `gem "rails", github: ...` line above the real
   `gem "rails", "~> 8.1.2"`, so it reported `nil` for an app actually on
   Rails 8.1.
5. **`line-height: 0` on logo/icon wrappers** — standard CSS idiom for
   collapsing inline-box whitespace under wrapped `<svg>`/`<img>` logos
   (amber `_brand.scss`). Audit now skips values below 1.0 for
   `line_height_too_low`.
6. **Workbox-compiled service workers** — minified bundles omit the literal
   string `NetworkFirst`; `Master::Rails::SwStrategy` detects
   `networkTimeoutSeconds`, `setCatchHandler`, and `navigate` route
   registration instead.

Numbers in the historical sections below are **after** fixes 1–4 — the
original audit snapshot before the CSS/PWA pass.

## Known audit-tool limitations (read before "fixing" these)

- **`public/lightgallery.css` is a vendored third-party library**, not
  hand-authored — same file, same findings, appears identically in both
  `brgen` and `shared`. Don't hand-edit it; if the findings matter, look
  for a newer lightgallery release or an override stylesheet instead.
- **No missing-view / missing-route / broken-link auditor exists yet.**
  Confirmed via a targeted search — nothing in `lib/design/` or
  `lib/judge/` checks for routes without a corresponding view, dead
  `link_to`/`*_path` references, or orphaned partials. Worth building if
  this keeps coming up; wire it as a fourth check alongside
  `Rails8AppAudit`/`PwaAudit`/`MobileFirstPwaProfiles` in
  `MobilePwaOperator#audit`.
- **`shared` isn't a real deployable app** — it's the common
  config/assets/frontend library the three real apps pull from, but
  `Rails8AppAudit.scan_all_deploy`'s app-discovery heuristic (any
  `RAILS/*` subfolder with an `app/` dir) picks it up as if it were one,
  hence the "red" verdict and "no PWA manifest" complaint — neither is a
  real gap for a shared library. Left as-is rather than special-cased in
  the tool; just don't chase `shared`'s PWA/doctrine findings as if it
  were a deployable app.

## Regenerate the live findings any time

```ruby
# from MASTER/, ruby -Ilib -e '...'
require "master"
result = Master::Rails::MobilePwaOperator.new.audit_all_deploy
result.value!.each do |entry|
  app = entry[:app] || entry.dig(:state, :app)
  puts "=== #{app} (#{entry[:verdict]}) ==="
  entry.dig(:design, :violations)&.each { |v| puts "#{v[:id]} #{v[:severity]} #{v[:file]}: #{v[:message]}" }
  entry.dig(:pwa, :violations)&.each { |v| puts "pwa: #{v}" }
end
```
Or per-app: `Master::Rails::MobilePwaOperator.new.call(intent: :audit_rails_pwa, app: "brgen")`.
