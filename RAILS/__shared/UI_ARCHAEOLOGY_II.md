# UI archaeology II

Selective carryover from pub, pub2 and pub3 continues here. The historical brgen application contributed explicit post/form feedback and compact action grouping; the current pass applies those ideas without restoring Bootstrap boxes. Early Amber contributed editorial pacing, wardrobe grids and large visual anchors; the current pass keeps those relationships while removing gradients, filters and shadowed cards. The marketplace generators contributed stepwise listing entry, photo capture, seller context, deals and cart/payment grouping; the current engine keeps those relationships but separates them with space and type. The playlist generations contributed player, queue and timestamped comment anatomy; pub3's fullscreen visualizer contributed safe-area and low-chrome discipline. Promotional surfaces remain distinct from editorial content: first-party vertical promotion can have identity, while third-party ad slots stay quiet and labelled.
