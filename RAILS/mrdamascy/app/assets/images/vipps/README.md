# Vipps brand assets

**`vipps-wordmark.svg` is the orange Vipps wordmark, unmodified, as Vipps
MobilePay publishes it in its own merchant plugin.**
https://github.com/vippsas/vipps-woocommerce/blob/052b7fd57365ec9c68e91a7b60df7af210bb61d2/payment/img/vipps-rgb-orange-pos.svg

It sits beside Vipps payment and login so customers recognise the payment
method. Use it as it is (no recolouring or stretching), and replace it with
the file from the merchant agreement's brand kit once that arrives.
