# Wishlist: making pub4 easier to work with (2026-10-28)

Written from one full working session on this tree by an outside coding agent
(GLM, 2026-10-28): the boot-crash diagnosis and fix (346da8e), the /fix
elevation engine (19c9c6b), the kanban content machine (1713e09), the RAILS ad
visual contract test (4e5636c), focused tests (663774d), README work (88b2ebb),
and a push audit across rebases. Each item names the friction that motivated
it and what already exists, because half of this list is "finish what the tree
started". Checkbox items live in TODO.md under "Agent ergonomics"; this file
carries the reasoning and the acceptance criteria.

## 1. A boot check that runs anywhere

Friction: `bin/master` died on the operator's Mac (Ruby 4.0.5) with
`NameError: uninitialized constant Master::Fix::Kernel::ConvergenceAdapter`
at `convergence_adapter.rb:11` after a rebase. Nothing in the repo exercised
the boot chain: `lib/master.rb`'s zeitwerk setup runs before
`bootstrap_container` loads builder → ai_boot → fix/kernel.rb, so every
managed constant is a pending autoload, and the crash fired only when a human
typed `bin/master`. No check in `rake audit` or `bin/check` would have caught
it, because none eager-loads the managed graph.

Exists: the fix itself — `remove_const(:X) if autoload?(:X, false)` guards in
`kernel/lifecycle.rb`; `test/test_cli_boot_e2e.rb` for the PTY surface (needs
pinned Ruby and the bundle); and the faithful-boot repro pattern that
reproduced this crash pre-fix and passes post-fix.

Wanted: a dependency-light boot check that eager-loads every zeitwerk-managed
constant, then references the three legacy aliases (`FixLoop`, `RepairLoop`,
`RunJournal`) and asserts object identity with their Kernel-owned classes. It
must run without the private bundle, so it works in any executor and on a
fresh clone. Wire it into `rake audit` so manifest validation, catalogue-drift
and design-token checks are joined by "the binary boots".

Acceptance: on a bundle-less checkout the check exits 0 on main, and exits
non-zero naming the offending file on a tree where an alias head const_sets
into a pending autoload — prove it by reverting 346da8e.

## 2. Retire the legacy constant aliases on the already-agreed gates

Friction: the alias heads are the most bug-dense pattern in the tree. Dual
names (`FixLoop`/`RepairLoop`/`RunJournal` vs
`Kernel::ConvergenceAdapter`/`RepairAdapter`/`LifecycleJournal`) make every
alias installation a require-time side effect, and each head needed its own
zeitwerk guard. The 346da8e crash was the canonical-name half of a guard pair
that only covered the legacy names.

Exists: the destination is already planned and gated — TODO's execution
contract says "Do not remove compatibility aliases until those gates pass",
the recovery gates are authored in `test/test_recovery_gates.rb`, and
`lib/fix/rename_sweep.rb` exists. Nothing here is a new plan.

Wanted: run the gates on the pinned Ruby, preserve receipts, then let the
sweep retarget every caller to the canonical names and delete the aliases in
one commit. Until then, every new alias head copies the 346da8e guard.

Acceptance: `grep -rn "const_set" MASTER/lib` returns only the single guarded
alias file (or nothing), and
`test_legacy_constants_resolve_to_the_kernel_owned_classes` passes against
canonical names or is deleted with them.

## 3. Tests that degrade gracefully without the private bundle

Friction: running one test file required stubbing `test_helper`,
gem-stubbing ruby_llm/tty-command/diffy/ferrum/mail, mirroring the tree with a
VERSION file and a RAILS light copy, and pointing RUBYOPT at a zeitwerk
checkout. An agent that cannot run tests asserts instead of verifying — the
exact failure mode the anti-simulation laws exist to prevent.

Exists: `MASTER/bin/verify-focused` (runs the TODO list, per-file exit codes);
the FinalCleanup dependency-light harness precedent (Minitest-only stubbed
helper, 3 runs / 17 assertions / 0 failures, recorded honestly as
focused-only); `MASTER/Gemfile` accepting >= 3.2 for constrained
environments.

Wanted: a `bin/test <file>` convention whose helper catches missing private
dependencies and reports `SKIP <file>: needs <gem>` with a clear exit, instead
of crashing at require. Tests for optional-integration features live in a
bundle-dependent group; the rest run standalone. Private gems become an
optional group in the Gemfile.

Acceptance: on a bundle-less checkout, `bin/test test/test_io_atomic_write.rb`
actually runs, and every file it cannot run prints one line saying why.

## 4. Close the one unguarded agent door

Friction: none observed — here the tree exceeds the wish. `AGENTS.md` and
`GEMINI.md` are generated from the marked block in `MASTER/AGENTS.md`, and
`rake lint:agent_contracts` fails when they disagree; `.cursorlaws` and
`.github/copilot-instructions.md` join them. `CLAUDE.md` is deliberately a
hand-written pure pointer that refuses to reproduce policy.

Wanted: keep CLAUDE.md hand-written but lint it — a check that fails if it
reproduces canonical configuration (grows past pointer scope) or contradicts
the generated block. The Rakefile comment says "one contract, four
harnesses"; Claude Code is a fifth harness reading a fourth contract, so it
is the one door with no alarm on it.

Acceptance: `rake lint:agent_contracts` (or a sibling task) fails when
CLAUDE.md is edited to contain law text or competing defaults.

## 5. A committed, linted tree map

Friction: "where does X happen?" cost a 34 KB file read and a six-hop
require-chain trace (`bin/master:357` → `master_boot.rb:171` → `:27` →
`builder.rb:5` → `ai_boot.rb:3` → `fix/kernel.rb:9` → `kernel/lifecycle.rb` →
`kernel/convergence_adapter.rb`).

Exists: `ruby MASTER/tools/agent_context.rb --tree` (depth 2, 2,000-entry cap)
for per-message handoff context, and the generated-docs pattern
(`docs/laws_digest.md` via `rake docs:laws_digest`) with lint-asserted
agreement.

Wanted: `rake docs:map` writing `docs/map.md` — per file: constants defined,
`require_relative` targets, and the entry-point/boot graph — plus
`rake lint:map` failing when stale. This complements `--tree` (which is
ephemeral context, regenerated per prompt), it does not replace it: the map
is greppable by humans and cheap for agents that cannot run the tool first.

Acceptance: adding a file under `MASTER/lib` without regenerating fails
`lint:map`, and the boot chain is named in exactly one place.

## 6. Smaller items, each one law entry or one small check

- **Requires declare, never act.** A laws.yml entry with a lexical detector:
  module-open-time `const_set`/`remove_const` outside the single guarded alias
  file is a violation. `rake lint:law_parity` already provides the
  enforcement-half contract. This one rule dissolves the autoload bug class
  behind items 1 and 2.
- **One Ruby pin, stated once.** TODO simultaneously records pins at 3.3.8
  (session note) and "pinned Ruby 4.0.5" (execution contract). One
  `.ruby-version`, one place that names it, and a check that doc mentions
  match the pin. The operator's machine and every executor stop guessing.
- **Fail-closed schema checks on read** for the `.master/*.json` ledgers
  (`fix_ideas.json`, `content_board.json`, schema 1, written through
  `Master::Io::AtomicWrite`) and the `.master` state files: a hand-edited or
  stale-schema file currently crashes wherever it is read. Refuse with the
  file path, the found schema and the expected schema — a crash becomes an
  instruction.
- **A rewrite policy for main, written down.** Commit a753291 ("Reconnect the
  messenger inbox rules and drop dead CSS and hooks") existed on the
  operator's Mac and nowhere upstream: a rewritten-away commit turned a pull
  into a rebase with skip messages and a stale base. If history rewrite is
  allowed, say so in AGENTS.md and what agents must run first
  (`git log --oneline @{u}..` before any rebase); if not, say that. Either
  way the human stops being surprised by skip messages.
- **Keep `docs/evidence/` as the receipt convention it already is.** The CSP
  probe note is the right shape: timestamp, raw observation, what would close
  it. Nothing to build — this is a "do not lose this".

## Already true (do not re-wish)

The tree already had, and this session relied on: generated, lint-asserted
agent doors; `agent_context --tree` handoff; law parity (every laws.yml entry
needs executable enforcement); atomic writes for ledgers; reachability and
instrument checks inside /fix; an evidence directory; a TODO whose items close
by deletion-with-evidence. The wishlist is mostly wiring existing disciplines
to boot, tests and docs, so machines catch what only humans catch today.
