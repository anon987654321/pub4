# Optional Irssi theme asset

`themes/default2.theme` preserves the neutral monochrome theme recovered from
`anon987654321/pub2/misc/default2.theme`.

This is configuration data, not a MASTER plugin or an enabled system change.
It has no effect unless an operator deliberately installs or selects it in an
Irssi configuration. Keep the original upstream/repository copy intact; this
copy is retained for provenance and reuse.

No runtime test is applicable to the theme by itself. Its migration check is
byte-for-byte equality with the source theme, plus verification that the file
lands beneath the existing `OPENBSD/` tree and does not add a root directory.
