# Optional Irssi theme asset

`themes/default2.theme` is an operator-authored neutral monochrome Irssi
theme. Its copy in `anon987654321/pub2/misc/default2.theme` was the source
used for this relocation into pub4; that path records where the file lived,
not third-party authorship.

This is configuration data, not a MASTER plugin or an enabled system change.
It has no effect unless an operator deliberately installs or selects it in an
Irssi configuration. The theme is preserved as authored; it is not presented
as an upstream theme or an independently developed replacement.

No runtime test is applicable to the theme by itself. Its migration check is
byte-for-byte equality with the author's existing pub2 copy, plus verification
that the file lands beneath the existing `OPENBSD/` tree and does not add a
root directory.
