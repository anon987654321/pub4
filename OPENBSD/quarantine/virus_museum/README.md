# Virus museum

Recovery pen for isolated historical material — content flagged and pulled
out of the live tree, kept as inert reference rather than deleted outright.

Rules enforced by `MASTER/tools/security_sweep.rb`:

- Every file here must be `.txt` (or this `README.md`) — never an executable
  extension, and never tracked with executable git file mode.
- Nothing here is run, sourced, or loaded by any part of this codebase.

This directory is currently empty; it exists so the sweep's structural check
has something to verify.
