# Amber - AI Fashion Assistant
**Version:** 8.0.0
**Stack:** Rails 8 + Solid Stack + Falcon + pgvector + LangChain

**Port:** dynamic (see `/etc/master_app_ports.conf`)

**Domain:** amberapp.com

## Overview
Amber is an AI-enhanced social network for fashion. Organize your wardrobe, get style suggestions powered by LangChain + OpenAI, and connect with fashion enthusiasts.

## Architecture
```
          CDN (Cloudflare)
                 │
          Load Balancer (relayd)
                 │
          Falcon (Rails 8)
                 │
    ┌────────────┴────────────┐
 PostgreSQL              Redis
 + pgvector           (Action Cable)
 (AI embeddings)
```

## Prerequisites
- Ruby 3.4+
- PostgreSQL 16 with `pgvector` extension
- Redis 7
- Falcon (`gem install falcon`)
- OpenAI API key

## Environment Variables
| Variable | Description |
|----------|-------------|
| `OPENAI_API_KEY` | OpenAI API key for LangChain style suggestions |
| `RAILS_MASTER_KEY` | Rails credentials master key |
| `DATABASE_URL` | PostgreSQL connection string via PgBouncer |
| `RAILS_ENV` | Set to `production` on server |

## Features
### Wardrobe Management
- Photo-based clothing catalog with ActiveStorage
- Smart organization and tagging
- Cost-per-wear analytics
- Usage tracking

### AI Style Assistant (pgvector + LangChain)
- Daily outfit suggestions via OpenAI embeddings
- Semantic similarity search on `organization_tips`
- Weather-appropriate recommendations
- Event-specific styling with vector{1536} embeddings

### Social Features
- Fashion feed with Turbo Streams
- Live chat via Action Cable
- Public chatrooms
- Outfit feedback from community

### Shopping
- Find pieces that match your wardrobe
- AI recommendations via LangChain
- Track purchases and budget

## Deploy
```zsh
# Generated by openbsd.sh — rc.d service at /etc/rc.d/amber
rcctl enable amber
rcctl start amber
```
